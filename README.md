## 🌿 Estrategia de Git

El proyecto utiliza una estrategia de ramas basada en **GitFlow simplificado**.

```text
main
 │
 └── develop
      │
      ├── feature/home
      ├── feature/*
      └── ...
```

### Ramas principales

| Rama        | Propósito                                            |
| ----------- | ---------------------------------------------------- |
| `main`      | Versión estable y publicada del proyecto.            |
| `develop`   | Integración de los cambios realizados por el equipo. |
| `feature/*` | Ramas temporales para funcionalidades específicas.    |

### Flujo de trabajo

```text
feature/* → develop → main
```

Las nuevas funcionalidades se desarrollan de forma independiente y posteriormente se integran en `develop`.

Una vez revisados y validados los cambios, se incorporan a `main` para su publicación.
